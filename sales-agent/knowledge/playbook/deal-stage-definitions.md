# 案件ステージの定義

更新日：2026-09-15／管理：営業部 山本
会議資料の数値は、この定義に沿って `scripts/pipeline_summary.py` が計算する。定義を変えたら、スクリプトの値も合わせて直すこと。

## ステージと確度

| ステージ | 定義（この状態になったら移す） | 受注確度 |
|---|---|---:|
| S1 初回接触 | 先方の担当者と初めて話した | 10% |
| S2 課題確認 | 課題のヒアリングを1回以上行った | 25% |
| S3 提案 | 提案書を提出した | 50% |
| S4 稟議・条件調整 | 先方が稟議を上げた、または上げると明言した | 75% |
| S5 契約手続き | 稟議が承認され、契約書のやり取りを始めた | 90% |
| 受注 | 押印済みの契約書を受け取った | — |
| 失注 | 先方から見送りの連絡を受けた、または90日以上連絡がない | — |

* **加重見込み** = 金額 × 受注確度
* 金額は年額（税別）

## 停滞の定義

次のどちらかに当てはまる進行中の案件を「停滞」とする。

* 最終活動から **14日以上** 経っている
* 同じステージに **30日以上** とどまっている

## 期限超過

* 「次アクション」の期限が基準日より前で、まだ完了していないもの

## 会議で扱う範囲

* 進行中（S1〜S5）の案件と、その週に受注・失注した案件
