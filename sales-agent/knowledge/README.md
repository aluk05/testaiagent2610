# knowledge/ — 会社と営業の知識

Agentが仕事の前に読む資料の一覧です。すべてデモ用の架空の内容です。
資料を追加・更新したら、この表の「更新日」も直してください。古い資料が残ると、古い答えが返ります。

| ファイル | 用途 | いつ読むか | 更新日 |
|---|---|---|---|
| `company/product-overview.md` | 自社商品「ApproveHub」の概要・強み・価格 | 商談準備、提案の論点づくり | 2026-09-01 |
| `playbook/sales-playbook.md` | 営業の進め方、ターゲット、商談の型、質問集 | 商談準備、会議での次の行動の提案 | 2026-09-15 |
| `playbook/deal-stage-definitions.md` | 案件ステージの定義、確度、停滞の定義 | 会議資料の作成（必読） | 2026-09-15 |
| `playbook/sales-rules.md` | 営業ルール（値引き権限、表現、情報の扱い） | すべての仕事 | 2026-08-01 |
| `cases/win-loss-notes.md` | 受注・失注の事例と理由 | 商談準備、停滞案件の打ち手 | 2026-09-30 |
| `past-meetings/` | 人が作った過去の週次会議資料 | 会議資料の作成（見本と前回比較） | 毎週 |
| `examples/deal-prep-memo_good.md` | 良い商談準備メモの見本 | 商談準備 | 2026-09-10 |
