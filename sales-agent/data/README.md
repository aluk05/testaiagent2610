# data/ — CRMの書き出しと議事録（読み取り専用）

デモ用の架空データです。Agentはこのフォルダを変更しません（`.claude/settings.json` で編集を禁止）。

| パス | 中身 | 本番での置き換え |
|---|---|---|
| `crm/snapshots/<日付>/deals.csv` | その日の朝時点の案件一覧（当日の活動は含まない） | CRMの読み取り専用接続 |
| `crm/activities.csv` | 商談・電話・メールの活動履歴 | 同上 |
| `minutes/customers/` | 顧客との商談の議事録 | 議事録ツール |
| `minutes/sales-meeting/` | 社内の週次営業会議の議事録 | 同上 |

* デモの「今日」は **2026-10-01（木）**。翌日 10/2（金）が週次営業会議と、エー商事との商談の日。
* 過去1回分の試行には `2026-09-24` のスナップショットを使った（`docs/trial-review_2026-09-25.md`）。
